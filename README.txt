In this repository, you will find all necessary materials for the non-stationarity paper. 
All analyses are conducted within the R software environment. 

Please also note the following:
(1) Prior to running any R scripts, you need to create empty "Output", "Figures" and "Maps" folders. 

(2) You need to run the "(00) Initialisation.R" script prior to running any other R script. 

(3) R4.5.0 was used to develop and implement all the R codes.
